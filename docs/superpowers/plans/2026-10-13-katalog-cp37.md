# Katalog PLP `/katalog` (CP-37) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Halaman katalog di `/katalog` dengan UI seperti Image 1 dan filter inti yang berfungsi penuh dengan data dummy (search, kategori, harga, sort, reset, pagination, stok-0 hidden).

**Architecture:** Query param adalah state (`validateSearch` zod + `useSearch` + `navigate` functional updater); satu seam `useCatalogData(query)` berisi adapter dummy sinkron (filter murni) yang nanti diganti adapter TanStack Query ke BE tanpa mengubah pemanggil.

**Tech Stack:** React 19, TanStack Router v1 (`validateSearch`, `useSearch`, `useNavigate`), Tailwind CSS v4, Base UI (via `components/ui`), zod v3, pnpm 9.

**Spec:** Desain disetujui user di chat 2026-10-13 (pendekatan A); riset `docs/research/katalog-cp37.md`; issue CP-37; visual Image 1 (tidak ada `docs/research/fe/shop.md` di repo — desain visual murni dari gambar chat).

## Global Constraints

- Semua tipe response/request API dari `@delysa/shared` — dilarang tipe API lokal duplikat (PRD-FE aturan keras).
- Validasi pakai zod; skema query katalog adalah turunan lokal dari `productQuerySchema` (`packages/shared/src/schemas.ts:15-19`) — kontrak shared tidak diubah.
- File route dilarang `export` komponen untuk `component/errorComponent` (aturan code-split PRD-FE).
- Tidak ada dependency baru; tidak ada perubahan `packages/shared`, API, atau skema DB.
- Perintah verifikasi hanya dari `apps/web/package.json`: `format`, `format:check`, `tsc --noEmit` (via `exec tsc --noEmit`), `build` (`vite build && tsc --noEmit`).

## Review Focus

- Ketik `?page=abc` atau `?sort=x` manual di URL — halaman tidak boleh crash/error boundary, filter fallback ke default.
- Hapus semua item lewat kombinasi filter (hasil nol) — empty state + tombol reset muncul, bukan grid kosong diam.
- Item stok 0 tidak tampil di grid TAPI tidak ikut mengurangi opsi faset yang masih valid.
- Search "buket wisuda" lalu tambah filter kategori — search tidak hilang (no redundant entry).
- Layar 320px — tidak ada horizontal scroll; sidebar turun di bawah toolbar.

## 1. Ringkasan & tujuan

Membangun halaman katalog `/katalog` (CP-37, prototype): breadcrumb + judul + trust chips, bar filter aktif + reset, toolbar (search debounce 300ms, select kategori cepat, select sort), sidebar faset (kategori checkbox, harga preset + min–max + terapkan), grid kartu (badge, rating+count, harga coret, `Sisa X`, tombol `+Beli` UI-only), pagination bernomor, empty state + reset, trust strip bawah. Filter bekerja penuh di atas dataset dummy; fetch BE dikerjakan nanti (CP-57) tanpa mengubah komponen.

## 2. Acceptance criteria

- Given `/katalog` dibuka, When halaman dimuat, Then tampil breadcrumb, judul "Katalog Rangkaian Bunga & Buket Atelier", trust chips, toolbar, sidebar, grid 12 item halaman 1, pagination.
- Given user mengetik di search, When 300ms tanpa ketikan, Then URL `?search=` terupdate, grid terfilter, page kembali 1.
- Given kategori dicentang / harga diterapkan / sort diubah, When diterapkan, Then grid + count + chips aktif terupdate; URL mencerminkan semua filter.
- Given kombinasi tanpa hasil, When filter diterapkan, Then empty state + tombol "Reset semua filter" (bukan grid kosong).
- Given item stok 0 ada di dataset, When grid dirender, Then item tersebut tidak tampil; item stok ≤5 tampil dengan badge "SISA X".
- Given URL diubah manual (`?page=abc&sort=salah`), When dibuka, Then fallback default tanpa crash.
- Given `tsc --noEmit`, `format:check`, `build`, When dijalankan, Then semua exit 0.

## 3. Asumsi & di luar scope

Mobile: sidebar stack di bawah toolbar, tanpa drawer (ditunda). Tombol `+Beli`/wishlist UI-only (`window.alert`) mengikuti pola `product-card.tsx` yang ada.

export type CatalogItem = Product & { stock: number; reviewCount: number; badge?: string };
